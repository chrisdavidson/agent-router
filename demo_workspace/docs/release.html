demo-shop 2.4.0

Released September 20, 2026. stable

Highlights

  • Order export to CSV from the admin dashboard.
  • Automatic retry for failed card payments (up to 3 attempts).
  • Faster checkout: median page load down from 1.8 s to 1.1 s.

Fixes

  1. Refunded orders no longer count toward monthly revenue.
  2. Session timeout on the login page now honours the "remember me" option.
